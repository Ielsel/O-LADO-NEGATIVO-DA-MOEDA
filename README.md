# O-LADO-NEGATIVO-DA-MOEDA 🎮
### Descrição
 "O Lado Negativo da Moeda" é um jogo de narrativa interativa em que você acompanha Gabriel Bernardes, um garoto de 13 anos, vivendo em situação de pobreza. Suas escolhas determinam o desfecho da história — será que você conseguirá encontrar uma saída para a família dele?

 O jogo foi desenvolvido durante o Ensino Médio, como parte do Curso Técnico Integrado a informática no IFB, utilizando tecnologias web básicas: HTML, CSS e JavaScript.

 ## 🎯 Objetivos do jogo
 <ul>
    <li>Proporcionar uma experiência interativa focada em narrativa e escolhas</li>
    <li>Refletir sobre os desafios sociais e econômicos vividos por pessoas em vulnerabilidade</li>
    <li>Aplicar conhecimentos de programação web em um projeto pessoal</li>
 </ul>

 ## ▶️ Como jogar
 <ol>
    <li>Acesse o jogo diretamente neste link: <a href="https://ielsel.github.io/O-LADO-NEGATIVO-DA-MOEDA/">O Lado Negativo da Moeda</a></li>
    <li>Aplique suas escolhas conforme as situações apresentadas.</li>
    <li>Cada escolha altera o desenvolvimento da história, levando a diferentes finais.</li>
    <li>Leia atentamente as opções e escolha com sabedoria para conduzir o destino de Gabriel.</li>
 </ol>

 ## 🛠 Como executar localmente
 ```
 git clone https://github.com/ielsel/O-LADO-NEGATIVO-DA-MOEDA.git

cd O-LADO-NEGATIVO-DA-MOEDA
# Basta abrir index.html no navegador
 ```

 ## Estrutura do projeto
 ```
/
├── index.html          # Página principal e estrutura de jogo
├── css/
│   └── styles.css      # Estilização visual do jogo
├── js/
│   └── script.js       # Lógica de narrativa e escolhas
└── assets/             # Imagens e mídia (ex: capa, sprites, fundo)
 ```
## 💡 Tecnologias utilizadas
<ul>
    <li>HTML5 – marcação da estrutura das cenas e opções</li>   
    <li>CSS3 – design, responsividade e efeitos visuais</li>
    <li>JavaScript – controle de fluxo, lógica de escolha e armazenamento de estado</li>
</ul>

## 📚 Aprendizados

<ul>
    <li>Domínio de manipulação do DOM e eventos em JavaScript</li>
    <li>Planejamento de narrativas ramificadas com múltiplos finais</li>
    <li>Organização de arquivos e projetos web</li>
    <li>Sensibilização sobre temas sociais por meio de design de jogo</li>
</ul>
